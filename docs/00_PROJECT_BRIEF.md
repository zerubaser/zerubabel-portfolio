# 00 — Project Brief

## Project
**zerubabel.et** — a premium personal portfolio for **Zerubabel Shimeles**, a full-stack developer based in Addis Ababa, Ethiopia.

## Who is Zerubabel
- Full-stack developer (web, mobile, backend, systems).
- **BSc Computer Science**, HilCoE School of Computer Science & Technology.
- **AWS Certified Cloud Practitioner**.
- Builds real, production business systems — not toy demos or templates.

## The Goal
Ship a portfolio that positions Zerubabel as a **builder of real business systems** — someone clients and employers trust with ERP/SaaS, clinic/lab platforms, LMS, mobile apps, and backend infrastructure. The site itself must be a proof of skill: fast, polished, original, and technically impressive.

## The Concept
**"3D Digital Command Center / System Universe."**
The portfolio is framed as an interactive command center / universe where each project, skill, and milestone is a node in a living system. It signals that Zerubabel architects and operates systems, not just writes code. The 3D experience is the differentiator that separates this from a template portfolio.

## What to Showcase
- Full-stack web development
- Flutter mobile app development
- Backend / API development
- ERP & SaaS platform development
- Clinic / lab management systems
- LMS (learning management systems)
- WordPress development
- Business / company websites
- Dashboards & admin panels
- Third-party API integrations
- Deployment & DevOps (AWS Lightsail, Nginx, PM2, Let's Encrypt)
- AI-assisted development workflow

## Target Audience
1. **Business owners / decision-makers** evaluating a developer to build a real system (ERP, clinic, SaaS).
2. **Hiring managers / recruiters / agencies** assessing full-stack capability.
3. **Fellow developers & technical peers** who can appreciate the engineering and the 3D craft.
4. **International remote clients** scanning for a credible, certified, English-fluent developer.

## Success Criteria
- Communicates "real systems builder" within the first screen.
- 3D hero loads gracefully, is performant on mid-range mobile, and degrades for low-end / reduced-motion.
- Case studies clearly show problem → solution → impact for each project.
- Confidential client work can be presented without leaking sensitive data.
- Admin can manage 100% of content (projects, skills, blog, settings, media) without code changes.
- Strong Core Web Vitals and clean SEO metadata per page.
- Runs reliably on a 0.5GB Lightsail instance (single PM2 process, swap-backed).

## Non-Goals
- Not a generic, template-driven portfolio.
- Not a public multi-user platform — single admin, no public registration.
- No Docker for the MVP.
- No e-commerce / payments.
- No heavy CMS dependency — the custom admin is the CMS.
- 3D is not loaded in the admin and must never block core content.
